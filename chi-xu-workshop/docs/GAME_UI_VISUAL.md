# 游戏视觉统一：青铜工坊

本轮只调整界面呈现、标题菜单导航与观察构图。原始牙模、预测矩阵、软件核对条件及存档结构不变。

## 视觉方向

- 保留工坊主题，使用深绿烤漆、黄铜包边、暖光和木质底座。全局颜色与通用游戏窗口在 `src/game-theme.css`，主工作台的仪表、任务槽与工具键在 `src/game-shell.css`。
- 标题页改为占满视口的实时 3D 牙模与叠加式主菜单，取消网页左右分栏和说明性章节列表。金色“进入工坊／继续工坊”为主入口，保留引导、旧三关和自由练习入口。
- 自绘 SVG 符号见 `src/ui.ts`，用于工具与菜单，不作为牙齿几何。按钮有图标、斜切角、内嵌高光、下压边和键帽；悬停、选中、禁用与键盘焦点均有独立外观。
- 任务、方案、回放统一为带金属标题条的浮动游戏面板；任务牙使用牙冠符号槽位，当前工具、当前牙、核对完成均保留文字／勾选反馈。
- 参考匹配仪表的分段条与圆环绑定真实匹配指数；没有新增虚构能量、联网状态、货币、成就或倒计时。
- 场景边角框、装饰齿轮、标题暗角与底座色调强化氛围，装饰使用 `aria-hidden` 且不拦截指针。光照与底座材质调整不改变牙冠网格或位姿。

## 布局与交互

- 首页可使用 ↑／↓ 选择主菜单，Enter 进入；表单与已打开的对话框不截获这些键。进入真实病例后沿用原有 G/R/F/H、手柄、取消、撤销及核对功能。
- 标题预览按菜单留白区域构图，桌面与手机分别适配相机视偏移和观察距离；只改变独立展示相机，不写病例进度。
- 主工作台继续保持完整视口、可收起面板和固定工具台。手机减小装饰、隐藏键帽文字提示，保留实际按钮与可见状态。
- 全部游戏模式和暂停／资源窗口共享基础材质。旧模式的导入说明仍只在工具窗口内显示，不进入标题主画面。
- 保留原生 button/select/checkbox 与清晰的可访问名称；工具图标对读屏隐藏。减少动画偏好下停用标题按钮的缓慢亮度效果。

运行 `npm test`、`npm run build` 与完整浏览器回归，覆盖标题主菜单、菜单键盘进入、真实 3D 手柄、手机布局、全病例连续结果、旧三关、自由练习、导入失败与存档保护。具体结果见 [验收记录](VALIDATION.md)。

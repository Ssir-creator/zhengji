# 观察挑战与直接操作

首页新增“观察挑战 · 短任务”。原参考排齐、旧版三关和自由练习继续保留。

## 如何玩

1. 进入短任务，先用视角按钮查看至少两个角度。第 1、3、5、7、9 张是“视角侦探”：从当前 3—4 颗中判断原始到参考的位移最大者；第 2、4、6、8 张比较 A/B 与蓝色参考轮廓，选出参考方案。均可重试，不设置倒计时。
2. 通过观察后，点击任务牙或对应卡片。先留下“需要平移／需要旋转／两者／无需调整”的判断，再开始操作。
3. “挪位置”显示真实世界 X/Y/Z 手柄，“转方向”显示对应旋转环；红 X、绿 Y、蓝 Z。拖动只预览，松手才保存；Esc 或“取消拖动”恢复已保存位姿。空白处拖动转动镜头，“放大观察”由玩家主动触发。手机也支持手柄触控。
4. 选轴后可点按或长按正反向按钮，勾选细调。粗调 0.25 u / 2°，细调 0.05 u / 0.5°；允许过头，移动后根据实际误差提示更近/更远，可撤销与重做。
5. “按住查看参考”临时显示目标轮廓，松开恢复。“参考轮廓”可主动开启/关闭；“前后滑帘”在同一镜头下显示原始与当前。上述只读显示不把未完成牙算作通过。
6. “双牙对照”后再选另一颗任务牙，同时突出两颗并列出参考误差；只移动当前选中牙。再次点击退出。
7. 每颗牙均需“核对这颗”。达到独立挑战的软件容差（0.075 u / 0.6°）后，明确记录上传矩阵的精确终点，并锁定该牙。用勾选、颜色与可关闭短提示音反馈；操作前判断另行反馈，不把答错当作治疗失败。
8. 本任务所有牙核对后，选择本次自评并保存，继续下一任务。全病例 28 颗连续保留：三批分别 9、9、10 颗，拆为九张任务卡（3/3/3，3/3/3，3/3/4）。完成一张不代表全病例完成。
9. 点击时间轴上的步骤或拖动进度条，只读回看。当时改变的文件编号、操作标签与画面同时显示。返回实际进度继续操作。“另开一次练习”仅重置当前短任务，使用独立重试存档；回首页再进入恢复正式挑战。

## 保存与边界

- 正式键 `chi-xu-workshop:reference-challenge:v2`；重试键为其后缀 `:retry`，不改 `chi-xu-workshop:prediction:v1` 或 `chi-xu-workshop:challenge:v1`。
- 每次有效操作先验证、保存，再应用状态。配额失败恢复原位姿；不兼容记录保留原文，不自动清空。
- 记录操作、逐牙核对、观察重试、主动开启轮廓、自评。长按参考不写记录；次数用来反思，不评价真实治疗优劣。
- 回放保留最近 400 个位姿操作，更早操作合并到回放起点；撤销/重做也记录实际位姿。撤销栈仅当前打开的任务有效，回放跨任务保存。
- 所有目标仍来自同一份已验证 `results.zip` 的 28 个刚体变换；原始 STL、GLB、病例清单、旧三关参数不改。仅对比位姿，不新增临床牙位、咬合、力学或安全性判断。
- 世界轴不是已审核的解剖方向；单位仍为 u。位置/方向判断依据原始至预测参考的变化和软件容差，不称临床适应证。模型预测不代表临床审核结果。

## 验证

本轮运行 `npm test`、`npm run build` 与完整 Playwright 浏览器套件。新增检查覆盖短任务全 28 颗连续终点、固定牙/观察门槛、回放一致性、400 步折叠、长按、参考/滑帘只读、Esc 取消、实际位置手柄与旋转环、手机尺寸、存储失败与旧进度隔离。浏览器的全病例流程使用目标附近的测试初态后，通过实际“核对/自评/继续”按钮完成；另有真实指针拖动测试，并不宣称测试者手工从原始位置拖完全部 28 颗。

实际渲染截图位于 `docs/screenshots/interaction-*.png`。Linux Chromium 使用软件 WebGL；Windows 本机性能及教学体验仍需在用户设备体验确认。

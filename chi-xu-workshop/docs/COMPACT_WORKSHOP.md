# 三段式观察挑战界面

主界面仅保留顶部任务行与全病例细进度条、完整 3D 牙模视区、底部“调整 / 视角 / 核对”三个入口。删除左右常驻工作台、标签页和舞台装饰外框。不更换病例网格、参考矩阵、关卡目标、核对容差和存档结构。

- 顶部任务行可点击展开当前观察题、操作判断或自评表单；关闭即返回完整视区。观察仍需两个视角，错例和顺序题仍须实际查看样例。选中一颗尚未判断的任务牙时，按需显示判断表单。
- “调整”展开小浮层选择挪动或转动。平移默认直接拖动牙齿，在当前相机平面内预览；旋转模式左右拖动，绕当前视线方向旋转。松手沿用原有保存、回放、撤销和存储失败回滚逻辑。空白区域仍旋转镜头。
- 细调、世界轴、正反向微调、可取消试步及传统 XYZ 手柄在“调整 → 精细调整”中，保留键盘 G / R 和 1 / 2 / 3。细调使直接拖动灵敏度降为 20%；传统手柄与直接拖牙互斥，避免同一指针操作同时修改两次。
- 视角入口下拉切换原有预设视角，另外保留放大与退远。展开视角或工具菜单时关闭其他临时面板，防止弹层遮挡菜单。
- 右上角“工具”包含参考轮廓、按住查看参考、双牙对照、前后比较、声音、方案试验、回放、导出、全屏与首页。“查看数值”内保留参考匹配数据，主画面不重复展示。
- 鼠标、单指触摸、Esc、pointercancel、lostpointercapture 和窗口失焦均有取消处理；取消只恢复预览，不写入进度。多指打断单牙拖动会取消预览，不提交半次拖动。触摸检查使用 Chromium CDP，不能代替所有手机原生浏览器验收。
- 原有旧版三关、自由练习与参考引导入口不受本次观察挑战布局改动影响。旧记录沿用原键与验证规则。

# 中文 / English

首页标题上方可直接选择“中文 / English”，默认中文。选择会记在当前浏览器，刷新或下次打开仍使用该语言。返回首页可再次切换。

覆盖首页、六关基础挑战、九任务、参考引导、旧版挑战与自由练习的按钮、任务说明、实时方向/核对反馈、参考提示、工具菜单、回放、自评和可访问名称。英文采用简短操作用语；“Perfect!”仍表示练习完成，不表示临床方案更好。

## 实现与维护

- `src/i18n-catalog.ts` 存放人工编写的中英文对应文案。完整句子优先匹配；动态编号、数值和镜头方向另行组合。新文案需同步补充词条。
- `src/i18n.ts` 在显示边界处理文本、无障碍名称、提示属性及原生确认框。MutationObserver处理各模式动态生成的反馈，保留原始文案以支持切回中文。不会重建3D场景。
- 语言单独存于 `chi-xu-workshop:language:v1`。游戏存档结构、内部事件、模型编号、姿态、判定和参考变换不翻译、不迁移。导出的原始记录保留原内容。自定义数据及未知技术错误不猜译。
- 下拉选项的程序值与显示文案分离；原本没有显式value的选项在翻译前保留源值。代码、输入内容及明确标记data-no-translate的节点不翻译。
- `src/i18n.css` 为英文长度和手机按钮换行做适配，保留暖白工坊风格。

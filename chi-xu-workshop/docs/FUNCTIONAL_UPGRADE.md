# 功能更新（界面风格待定）

本次保留现有主题；不采用设计提案图作为运行画面。不改真实牙模、旧三关参数、预测终点或已有存档。

## 九个短任务的观察内容

1. 平移距离最大的一颗（原始枢轴到参考枢轴）。
2. A/B 中与预测参考重合的一份。
3. 最短旋转角最大的一颗。
4. 位置已到、方向未到的只读错例。
5. 方向已到、位置未到的只读错例。
6. 平移过头、旋转未完成的只读错例。
7. 平移距离最小的一颗。
8. 六步顺序试验：同一世界轴平移和同一固定枢轴旋转交换顺序。当前数学模型中终点相同，不假造碰撞或临床顺序效果。
9. 最终复核错例：位置超出容差，方向已到。

仍须从两个视角观察；错例题须先查看样例，顺序题须看完两个顺序。样例只读，先前已完成的任务不重置，当前已通过观察的记录继续有效。没有牙位、解剖方向或治疗严重程度推断。

## 可取消试步

“先预览反向／正向一步”只显示复用真实网格的轮廓、方向和误差前后对比，不写存档或计步；“应用试步”才进入正常保存和回放。Esc、取消、切换工具／轴／细调或离开操作会清除试步。方向文字随相机投影变化，明确区分向屏幕方向、朝向／远离观察者和旋转弧线。

## 启动与更新

- 新版本本地 Vite 服务提供安装身份端点。同一安装再次启动时打开现有页面，跳过并行更新和第二个服务；不杀任何占端口进程。旧版或其他服务无法确认身份时仍给出具体说明。
- 更新锁记录 PID、主机与所有权 token；确认进程死亡才恢复。旧空锁需超过两分钟且确认无其他更新进程；无法确认时保留。恢复将旧锁改名留存，使用恢复互斥目录串行处理，不删除他人锁。
- 原浏览器、原用户资料与 `http://127.0.0.1:5173` 保持一致。刷新只读取本地已安装代码，不从 GitHub 安装新版。
- 云端检查不等于用户电脑上的 Windows 原生验收；PowerShell 进程扫描与浏览器唤起仍需用户实际确认。

## 开放过程试验

方案面板提供三种可自选过程目标：位置差距缩小至少 40% 且方向不变差；方向差距缩小至少 40% 且位置不变差；两项差距均缩小至少 40%。下限使用已有新挑战容差，已在容差内的分量不能反复刷试验。允许多个不同的中间位姿满足目标；不以最少点击评价玩家。

试验从所选牙的当前实际位姿开始，按实际进度实时判断；只读样例、试步轮廓和回放不算达成。试验目标是当前会话的练习工具，重新进入可重新开始；达成位姿可用原有“保存当前尝试”功能保留。它不替代最终参考核对，不是临床指标，不模拟接触、碰撞或咬合。

# 看得懂方向，打开即检查新版

## 画面内的直接操作

- 选中牙齿后，牙模画面内显示操作按钮，不必先滚到任务卡下方找提示。任务卡将“位置 / 方向”改为“挪位置 / 转方向”。
- 绿色直箭头表示平移，弧线表示旋转；按钮显示“向左挪”“向右上挪”“顺时针转”等当前画面方向。切换预设视角、拖动相机、改变尺寸时同步重新投影。
- 正对平移轴时显示“朝向你 / 远离你”和 ⊙ / ⊗；旋转轴接近画面平行时只说“沿弧线转”，不冒称可见的顺逆时针。
- 默认显示选中任务牙的真实目标位姿轮廓，实际牙模不会自动吸附；点击一步后反馈更近、更远、已对齐或边界。撤销与重做仍可用。
- 恢复第二关存档时初始化该关允许的操作轴，避免沿用第一关的 X 轴。
- 方向名称只描述当前屏幕，不推断上下颌、近远中、颊舌侧或临床方向。使用既有牙模与目标位姿，步长、允许轴、边界、容差、三关继承、固定牙规则和存档键均保持原样。

## Windows 自动更新

旧版本先双击一次“更新游戏.cmd”，再从“开始游戏.cmd”或桌面“齿序工坊”打开。之后每次从该入口启动：

1. 在开启游戏服务前运行现有更新器，读取远程版本。
2. 版本相同不下载；有新版自动下载、解压、构建、完整备份并更新原路径。
3. 更新失败提示原因并尝试打开本地版本；首次依赖安装仍需要网络。
4. 刷新桌面快捷方式，用新进程加载更新后的启动器，继续使用固定的原地址。

修改发布后，关闭旧黑色启动窗口、重新双击桌面入口即可检查新版。单独刷新仍在运行的网页不会更新远程代码。Git 开发工作区与本机验收进程不自动更新。不会关闭用户其他服务或清理浏览器存档。

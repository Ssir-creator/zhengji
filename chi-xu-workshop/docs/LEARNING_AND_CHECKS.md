2026-10-21，本轮在 `chi-xu-workshop-dev` 完成；工程以外、main、真实网格、病例清单、关卡目标与容差均未改动。

## 已实现的游戏功能

- 标记改为牙列外侧的编号与细引线，按屏幕投影排列并保持间距；随镜头、缩放和屏幕宽度重排。只计算显示位置，不推断牙位或重造几何。
- 首次操作教学要求实际完成选牙、移动一次、撤销一次，再展开完整工具栏。可跳过；教程完成偏好使用独立键 `chi-xu-workshop:tutorial:v1`。继续旧存档不强制重新教学，也不改变挑战存档 schema。
- 挑战中、复查和过关后可切换本关“调整前／调整后”。起点是该关继承的全牙位姿；对比只改变显示，禁用编辑和撤销，不写入挑战进度。退出或转关恢复真实当前位姿。
- 过关反馈说明本关练习了什么，展示任务牙相对本关起点的实际位移与转角，保留非任务牙检查，提供可展开的思考题答案。
- 学习说明是软件位姿练习的反馈，不将未知牙位、u 单位或未审核病例变成临床教学结论。

## Windows 本机验收

更新后，先关闭游戏启动窗口，再双击 **检查游戏.cmd**。

检查会：

1. 检查 Node.js、依赖、目录写入和真实 28 冠显示文件的 SHA-256。
2. 检查更新服务器是否可达，读取本机上次成功更新记录；没有记录时明确标为“待确认”。本次检查本身不替换游戏文件。
3. 在 Windows 上创建或刷新当前目录对应的桌面启动、更新快捷方式；通过实际“开始游戏.cmd”启动服务。
4. 在原浏览器打开本地检查页，验证真实模型加载、WebGL2、临时存储读写和挑战存档原文保持不变。报告不包含进度内容或病例文件。
5. 保存 **本机检查结果.local.json**，随后关闭检查自己启动的服务。之后双击“开始游戏”正常游玩。该报告在 Git 中忽略，不上传远程；更新器会保留本机配置文件。

检查服务只监听 127.0.0.1 的临时端口，使用临时令牌接收来自游戏地址的限定报告。已有 5173 服务不会被检查器关闭，会提示先关闭旧启动窗口。localhost 与 127.0.0.1、不同浏览器的进度仍各自独立，检查报告会说明实际地址。

**此仓库中的 Linux 检查不能替代用户 Windows 实机结果。** Windows CMD、桌面入口、Windows 解压/更新是否在用户电脑正常，必须以该电脑实际运行后的报告为证。当前没有收到用户的本机报告，因此这一项仍待确认；不能凭开发完成宣称用户电脑已通过。

## 自动化验证证据

- `npm test`：44/44 通过。包含标记布局、实际变化计算、报告字段校验、只接受游戏来源与令牌的报告接收器、真实病例预检和现有更新失败恢复测试。
- `npm run build`：TypeScript + Vite 通过，保留原有 Three.js 主包体积提示。
- `npm run test:browser`：14/14 通过。包含真实连续三关、存档恢复、LOD、固定牙、自由练习隔离、回放、实际操作教学和只读对比。
- 教学提示位置及窄屏等待逻辑收尾后，受影响的教学、首页和玩家体验 6 项复测通过；补充挑战中对比禁用撤销与移动的断言后，相关 2 项再次通过。
- `node scripts/test-machine.mjs`：实际启动 → Chromium 打开检查页 → 模型与 WebGL → 临时存储 → 原进度不变 → 报告写入 → 检查进程退出，完整流程通过。报告把 Linux 无法验证的 Windows 项保留为 pending。
- 另用测试进程占用 5173，检查器按预期返回失败并保持该进程存活。
- 最初一项新增浏览器测试因同时匹配侧栏和工具栏的两个“检查”按钮而失败；已限定为工具栏按钮，未放宽游戏断言。

可重复的机器端到端测试依赖已安装的 Chromium；Linux 默认 `/usr/bin/chromium`，其他环境通过 `CHROMIUM_PATH` 指定。Windows 普通玩家直接使用“检查游戏.cmd”，无需安装测试浏览器。

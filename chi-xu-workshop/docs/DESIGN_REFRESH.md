# 工作室视觉改版与交互配色

日期：2026-10-19。范围仅为 `chi-xu-workshop-dev` 中的独立游戏；不修改 main、原科研网站、真实牙模、病例配置、关卡参数或存档格式。

## 参考与提炼

按用户要求阅读 [UI UX Pro Max Skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill/blob/56ea9cf174ed86786187daa9de0e6247cb0747e4/.claude/skills/ui-ux-pro-max/SKILL.md)，包括 quick-reference 和 pro-rules。只在 `/tmp` 克隆阅读，没有向项目安装插件或增加运行依赖。

完成设计系统检索 `educational game tactile workshop`、样式检索 `editorial minimal analog`、Three.js 检索 `selection hover material feedback` 和 UX 检索 `color state not alone`。初始聚合结果的营销页结构、黏土卡片和儿童英文字体不适合本项目的真实模型工作流，因此没有照搬；后续样式检索返回 Minimalism & Swiss Style，采用其中网格、留白、文字层级和克制的装饰原则。

实际采用的要点：

1. 先确定产品语境，再挑选风格。首页使用中文衬线大标题、纸色与炭黑，真实模型承担主体画面；不新增概念图或外部在线字体。
2. 用字号、对齐、留白和细线建立层级，取消层层圆角、重复绿色卡片、厚阴影和无功能的装饰符号。
3. 色彩表达交互状态，同时保留任务编号、文字、完成勾和固定标识；不以颜色独自传达信息。
4. 保留点击、键盘和微调按钮；提供可见焦点、44px 控件、选中按钮的 `aria-pressed` 和减少动画设置。
5. 材质状态独立于病例与保存数据，仅在状态改变时更新材质并标记重绘，不重建网格或修改牙齿位置。

用户随后提供的小红书参考笔记在当前云端经代理请求时返回 `403 Forbidden`，未能读取具体游戏或图片。本轮配色依据用户的交互描述设计，不声称复刻了该笔记中的作品。未把分享链接的临时令牌保存进项目。

## 显示状态

| 状态 | 颜色 | 补充标记 |
| --- | --- | --- |
| 普通牙 | 自然牙白 `#eee5d3` | 非任务牙不显示操作任务卡 |
| 待调整任务牙 | 浅杏色 `#e8b487` | 任务编号与任务列表 |
| 悬停牙 | 蓝色 `#9dcbdc` | 指针反馈；移出恢复原状态 |
| 当前可操作牙 | 琥珀色 `#f1ac46` | 选中框、当前任务文字、操作手柄 |
| 已达标任务牙 | 青绿色 `#88b9a5` | 完成勾与完成文字；继续移离目标会恢复未完成色 |
| 第三关固定标记牙 | 灰蓝色 `#aab8bb` | 固定文字和标识，不染成可操作色 |

固定状态优先，其次完成、可编辑选中、悬停、任务、自然色。查看其他牙不赋予可编辑选中色。回放时不按最终位姿给中间画面标完成色。以上均为游戏提示色，不代表组织属性、医学异常或治疗判断。

## 本机更新与刷新

GitHub 推送只更新远程代码，不会自动替换用户电脑中的 ZIP 解压文件。ZIP 下载版现已提供一键更新：先关闭旧服务，双击“更新游戏”，完成后从原目录重新启动；较早版本需要先安装一次新更新器，见 [Windows 一键更新](WINDOWS_UPDATES.md)。之后继续使用同一浏览器、同一主机名与端口读取原存档；不要清除浏览器站点数据。

如果正在运行的 Vite 开发服务所用目录里的源码已经更新，Vite 通常会热更新，必要时刷新即可。仅刷新仍在运行旧目录的页面，不能获取远程新提交。

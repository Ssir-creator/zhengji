# 玩家界面改版：按试玩反馈调整

本次依据用户试玩后的三个问题实施：像查看网站、专业信息太多、进关不知道做什么。本次修改的是呈现和操作引导，继续保留真实28冠、同病例连续三关和隔离自由练习。

## 玩家现在能看到什么

- 一整张工作台作为主场景，顶部三个挑战节点、侧边小任务卡、底部操作托盘；不再把画面放在文档式查看器框中。
- 三关使用易懂的显示标题“腾出一点位置”“把这颗牙挪正”“一起检查一下”。内部关卡ID、原教学配置和存档字段不改。
- 只给本关要调整的牙添加①②③任务标记。它们是关卡内的任务次序，绝不是FDI、上下颌或原始文件编号。原文件编号仍在详情与导出中保留。
- “先做什么”由当前状态生成：选任务牙、沿绿色箭头挪一点、位置好了切换旋转、当前牙好了换下一颗、全部好了检查过关。
- 点击不该动的牙后，任务卡直接提供“去调整①号任务牙”入口，避免一屏灰色控件却不知道如何继续。
- 每颗任务牙分开显示位置与方向的进度及文字状态。达标后仍可继续调整，若回退会立即取消完成；没有隐藏总分或排名。
- 主界面操作为“挪一挪 / 转一转 / 顺着箭头 / 反向一点 / 撤销 / 重做 / 检查一下”。自由练习保留手动选轴入口。
- 坐标、数值误差、帧率、三角面数、采样测距、轮廓对照、导出与资源核对信息收进详情或菜单；不会把未计算检查变成通过。
- 结果仍由玩家复查、保存才生效，完成后呈现徽章与下一关入口。

## 保持不变

`src/core.ts`、病例清单与所有牙模资源均未改变。目标、容差、锁定条件、三关扰动、初始快照、保存键/schema、资产内容指纹和自由练习隔离保持不变。

方向提示将当前目标差与允许轴对应为正/负方向；按钮仍只执行原本0.25u或2°的一小步（精细模式仍可用），生成完整可撤销命令。没有自动吸附、自动完成、改写目标、改变牙齿形状或绕过容差。玩家也可以反向尝试、拖动手柄、撤销并重新观察。

本次反馈优先于原PRD中的常显技术HUD：这些内容现在按需查看。绿色方向提示主动呈现以改善任务可理解性；三级提示和目标轮廓仍可关闭，目标轮廓默认关闭。没有添加经营、计分榜、计时惩罚或新的临床机制。

## 验证范围

新增6项逻辑检查覆盖任务次序标记、误选恢复、正负方向、位置/方向分开、第三关保留条件、达标回退与无吸附。

新增浏览器检查覆盖：主界面不出现技术读数；误点可返回当前任务；方向按钮只移动允许牙的一小步；撤销恢复；桌面尺寸下任务与操作入口可见；兼容旧schema1的真实病例进度。完整三关和原有存档/几何回归继续运行。

这些是软件检查，不能代替用户再次试玩后的“是否像游戏”“是否看懂任务”反馈。真实牙位、单位、邻接和教学角色仍未审核；目标GPU、触屏及用户教学效果的限制继续保留。

## 渲染与点击修正

整屏场景改为按需绘制；相机或牙齿变化、选中/悬停、轮廓过渡及窗口缩放会触发更新，静止时不持续绘制。阴影仅在几何或场景变化时刷新。此调整减少静止消耗，不代替目标GPU实测。

任务标记按下时保留锚点，防止通用按钮按压变换使标记跳离鼠标。标记选择、卡片选择、手柄拖动及取消都保留回归检查。

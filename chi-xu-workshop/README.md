# 齿序工坊 · Chi Xu Workshop

依据 48 页《齿序工坊_Claude完整阅读版.pdf》实现的独立浏览器 3D 正畸教学游戏开发版。**现已接入用户上传的 28 个真实 STL，可直接进入三关和自由练习。** 不修改或依赖原科研网站，不需要模型推理后端。

真实资产已经取得，但单位、上下颌、FDI、真实邻接、数据使用范围和教学目标尚未经过项目方/教师审核；当前是 PRD 原型位姿练习，不能称临床教学审核或全部 P0 验收已完成。

## 玩家界面已按试玩反馈改版

进入后直接查看标记牙和下一步动作，用“挪一挪 / 转一转 / 顺着箭头”逐步操作。误差、坐标与测量移入“查看细节”，菜单可查看资源信息。三关规则、牙模与存档格式不改，旧进度可以继续。详见 [玩家界面改版说明](docs/PLAYER_REDESIGN.md)。

## 启动

Node.js 24 LTS 推荐（运行应用最低 22.12+）。将工程内容解压到 `D:\正畸_严肃游戏` 后，在该目录运行：

```powershell
npm ci
npm run dev
```

打开终端显示的本地地址。也可运行 `scripts/start-windows.ps1`。云端工作目录：`/workspace/zhengji/chi-xu-workshop`，依赖安装使用 `npm ci --cache /workspace/.npm-cache`。

**不需要每次重新导入牙模。** “开始新的挑战”“继续进度”“进入自由练习”会自动校验并加载随工程附带的真实病例。新挑战覆盖旧进度前会明确确认。模型和记录保留在本机，不建立远程遥测。

- 原始坐标、模型单位 u、未知 FDI=null、上下颌 unknown。无已确认邻接表时测距为未计算；穿透检查仍未实现。

## 参数与数据

第一关模型 3/5 的目标 X 为 +1.50u/−1.50u；第二关模型 4 回原始参考位姿；第三关 3/5 的目标 X 为 +1.00u/−1.00u，6 回参考，7 固定。初始状态同时设置模型 4 的 Y +4u/Z +18° 与模型 6 的 Y −1.5u/Z −6°，确保以后每关完整继承上一关快照，不在转关时额外叠加扰动。

位置/朝向通关容差 0.35u/3°；固定漂移容差 0.00001u/0.001°。默认微调 0.25u/2°，精细选项 0.05u/0.5°。这些是软件参数，不是临床标准。

默认最少轴配置依据原型位姿任务建立；全部自由度与数值边界仍须教学审核。原始位姿不称为临床理想排牙。

进度使用 `chi-xu-workshop:challenge:v1`，与完整病例清单指纹及版本绑定。版本不兼容时保留旧原文供导出。自由练习不写入挑战键；回放只插值临时显示。原始 STL 不改写。

## 更换病例或重建显示资源

原始检查：

```powershell
node scripts/inspect-assets.mjs --source "D:\论文复现\CLIK-Diffusion-main\Data\256_crown\initial" --out case.draft.json
```

只记录实际文件名、SHA-256 和大小，模型 ID 留空，不覆盖已有输出。人工核对 JSON 后，可在“病例资源”选择清单与 28 个对应 STL。本机导入模式刷新后需重选文件；**内置病例不需要**。

制作内置 GLB（Node.js 24）：

```sh
node scripts/prepare-case.mjs --source public/cases/initial/original --out public/cases/initial
```

该步骤可重建显示派生资源；绝不更改原始文件或按概念图重造牙齿。没有共享的原型源码或原科研网站源码，本工程为独立实现。
